# コストコ価格比較 Web MVP

## 目的
コストコ売り場で「今、この商品を買うとオンラインよりどれくらい得か」を短時間で判断するためのWebアプリです。

## 現在の方針
完全自動化ではなく、アナログ入力と自動処理を組み合わせます。

- 人がする：値札を撮る、商品番号・商品名・店頭価格を確認、オンライン価格を確認、買うか判断
- Webがする：価格差・節約率計算、個数反映、一覧化、合計、個数修正、削除

有料AI/APIは使っていません。

## 機能
- iPhoneから値札を撮影 / 写真選択
- 商品番号・商品名・店頭価格の入力
- コストコオンライン検索への導線
- 店頭価格 / オンライン価格の色分け比較
- 節約額・節約率の自動計算
- 購入チェック、個数指定
- 複数商品の追加
- 買い物一覧で個数修正・削除
- 最終画面で店頭合計 / オンライン合計 / 節約額
- 最終画面でも個数修正・削除
- リセット
- ブラウザ内保存

## 開き方
`index.html` をブラウザで開いてください。

## 公開
GitHub Pagesなどの静的ホスティングへ、このフォルダのファイルをアップロードすれば公開できます。

## 注意
コストコオンライン側の検索URLやサイト仕様が変更された場合、検索ボタンのURL修正が必要になることがあります。
